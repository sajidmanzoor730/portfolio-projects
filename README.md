# Sajid Manzoor — Operations & Technical Portfolio Projects

A collection of demonstration projects created to show practical approaches to executive operations, CRM/data quality, reporting, process documentation, lead follow-up, and automation.

> **Note:** Demonstration datasets are fictional/sample data and are not from real clients.

## Projects

### 1. Executive Operations Dashboard
Tracks meetings, priorities, action items, deadlines, owners, and follow-ups.

**Tools:** Excel, Google Sheets concepts, Operations

### 2. CRM Data Quality & Cleanup
Demonstrates normalization, duplicate review, enrichment, and data-quality checks.

**Tools:** CRM concepts, HubSpot concepts, Excel/SQL concepts

### 3. Operations SOP & Runbook
Demonstrates onboarding, access management, recurring tasks, and issue-escalation procedures for a remote operations environment.

**Tools:** Notion concepts, SOP documentation

### 4. KPI Operations Dashboard
Demonstrates reporting for completion, QA accuracy, SLA achievement, status, and operational trends.

**Tools:** Excel, PivotTables, reporting

### 5. Lead Follow-up Pipeline
Demonstrates lead stages, owners, priorities, follow-up dates, next actions, and pipeline visibility.

**Tools:** CRM concepts, Excel

### 6. Python & Bash Automation
Small demonstration utilities for system health checks and log review using local/sample data.

**Tools:** Python, Bash
